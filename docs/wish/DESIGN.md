# Wish design — academic

Treat the repository as an academic **source-of-truth library**, not merely a website.

- canonical data/assets should be edited at their owner;
- generated manifests and presentation surfaces should be reproducible;
- public sites/CVs consume this source rather than silently becoming competing truth;
- provenance matters more than convenient manual duplication.

A good change makes academic facts easier to reuse while keeping their source and publication status explicit.
